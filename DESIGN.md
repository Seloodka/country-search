# 1. Отмена устаревших запросов

- **Устройство**: Отмена устаревших запросов реализована через функцию `createNewAbortController`, которая в замыкании хранит предыдущий запрос, а при новом вызове абортирует его. Вызывается при наборе текста в поле для поиска и возвращает новый аборт контроллер для нового запроса.

- **Почему**: Просто для понимания (моего особенно :) ), гарантирует отмену любого предыдущего запроса при вводе нового символа, даже если `debounce` уже отправил этот запрос.

# 2. Обоснование выбранной задержки `debounce`

### Задержка: 500ms

- **Обоснование**: Половины секунды достаточно чтобы отсеять быструю и средней скорости печать. Это позволит уменьшить количество запросов и нагрузку на сервер к котору обращается fetch. Так же пользователю не надоест ждать отклика интерфейса на его действия.

- **Что будет если убрать**: Будет отправляться слишком много запросов, а если они не отменяются, то можно получить блокировку со стороны API, а так же быть признанным злостным дудосером. Так же может возникнут гонка запросов, когда полее старый запрос резолвнется позже и будут отрисованы именно его данные а не фактически последнего запроса.

- **Что будет если сильно увеличить**: Пользователь выйдет устав ждать. Запросы будут отправятся с большой задержкой, с одной стороны - это облегчит нагрузку на сервер, с другой - терпение пользователя не бесконечно. Особенно, если не выведена какая-либо индикация, что запрос в процессе.

# 3 Сложность Big(O) для `mapCountryResponse`

| Сложность                                                     | Почему                                                                                                                                                                                                                                          |
| ------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| O(N), где N это количество полученных стран от запроса к API. | `mapCountryResponse` проходится по каждой стране 1 раз O(N). Внутри есть циклы прохода по языкам и валютам (L + C), они в свою очередь не зависят от N, размер их массивов ограничен для каждой страны. Более точная сложность - O(N * (L + C)) |

- В текущем варианте у меня кешируются ответы от API для того, чтобы не создавать одинаковые запросы, `mapCountryResponse` вызывается, даже если запрос и его ответ был занешифрованн, поэтому на сложность не влияет.
